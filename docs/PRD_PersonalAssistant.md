# Personal AI Assistant - 产品需求文档

**版本**: v2.0
**创建日期**: 2026-01-30
**文档状态**: 设计中

---

## 1. 产品愿景

构建一个**个人化的多 Agent AI 助手平台**，整合多个大语言模型，通过专业化的 Agent 协助用户在不同领域的工作和生活：

- 学习（英语、成长）
- 工作（开发工具、笔记管理）
- 投资（股票分析）
- 资源管理（收集整理）

**核心理念**：一个入口，多个专业 Agent，按需调用，协同工作。

---

## 2. 目标用户

**主要用户**：个人开发者/技术人员

**用户画像**：
- 需要学习英语提升技能
- 日常有大量笔记和知识管理需求
- 需要 AI 辅助编程开发
- 有投资理财需求
- 持续学习成长
- 需要收集和管理各类资源

#### 3.2.2 Note Manager Agent（笔记管理）

**核心功能**：
- [ ] Notion API 集成

```

         AI 分析/建议
```

## 4. 系统核心能力

### 4.1 多模型支持

**已支持的模型**（从现有项目继承）：
- Claude (Anthropic)
- DeepSeek
- Gemini (Google)
- Grok (X.AI)

**待支持**：
- OpenAI GPT-4
- 本地模型（Ollama: Llama, Qwen）

**模型选择策略**：
- 用户可手动指定
- 系统可根据任务类型自动选择
- 成本/性能平衡配置

### 4.2 Agent 协作机制

**协作模式**：

1. **顺序调用**：A 完成后触发 B
   ```
   用户: "帮我写一篇英语日记，然后保存到 Notion"
   → English Tutor (生成日记)
   → Note Manager (保存到 Notion)
   ```

2. **并行调用**：同时执行多个 Agent
   ```
   用户: "查一下茅台的股价和最近的相关新闻"
   → Investment Advisor (查股价) ║ Investment Advisor (查新闻)
   ```

3. **主从调用**：主 Agent 调用子 Agent
   ```
   Growth Coach 制定学习计划时
   → 调用 English Tutor 获取英语学习建议
   → 调用 Resource Collector 获取学习资源
   ```

### 4.3 上下文管理

**会话上下文**：
- 单次对话的上下文保持
- 可引用之前的对话内容

**Agent 记忆**：
- 短期记忆：当前会话
- 长期记忆：用户偏好、历史数据（存储在数据库）

**跨 Agent 上下文传递**：
- Agent 之间可共享必要的上下文
- 通过 Context Manager 统一管理

### 5.2 交互方式

1. **对话式交互**（主要）
   - 自然语言输入
   - 系统自动识别意图并路由到对应 Agent
   - 或用户手动选择 Agent

2. **快捷命令**
   ```
   /note create "标题"     - 创建笔记
   /stock 600519          - 查询股票
   /english daily         - 每日英语练习
   /resource add [URL]    - 添加资源
   ```

3. **快捷按钮**
   - 常用操作一键触发

## 6. 技术要求

### 6.1 性能要求

| 指标 | 要求 |
|------|------|
| API 响应时间 | < 500ms（不含 AI 调用） |
| AI 首字响应 | < 2s |
| 页面加载时间 | < 2s |
| 并发 Agent 数 | 支持 3 个同时运行 |

### 6.2 数据要求

| 数据类型 | 存储位置 | 备份策略 |
|----------|----------|----------|
| 用户配置 | 本地 SQLite | 定期导出 |
| 对话历史 | 本地 SQLite | 可选云同步 |
| 笔记数据 | Notion | Notion 自带 |
| 学习记录 | 本地 SQLite | 定期导出 |

### 6.3 安全要求

- API Key 本地加密存储
- 敏感操作需要用户确认
- 代码执行在沙箱环境
- 不上传敏感个人数据到第三方
