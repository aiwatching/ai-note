# eng — 绕道练习

## 这在训练什么

用户词汇是从阅读进来的，路径单向：`英文 → 意思`。说话需要反向：`意思 → 英文`。
卡住那一刻真正的错误动作是**在追求那一个正确的词**。

所以训练目标不是词汇，是**放弃最优解、用手边的词绕出来的习惯**。

数据在仓库的 `engdata/entries.jsonl`，和 CLI（`eng.py`）、网页版（`web.py`）共用一份。
放在仓库里是为了云端会话 clone 下来就能直接用 —— 手机上 claude.ai/code 打开这个仓库，
`/eng` 就能练，练完的记录跟着 git 回到 Mac。**API key 不在仓库里**（在 `~/.eng/config`）。

## 工具

所有状态变更走这个脚本，路径相对本 skill 目录：

```bash
python3 .claude/skills/eng/drill.py review               # 复习清单
python3 .claude/skills/eng/drill.py next                 # 下一题
python3 .claude/skills/eng/drill.py say <id> <文本>       # 存一遍，返回重复分析
python3 .claude/skills/eng/drill.py finish <id> [better] # 收尾，返回内置参考说法
python3 .claude/skills/eng/drill.py add <中文>
python3 .claude/skills/eng/drill.py used <id>
python3 .claude/skills/eng/drill.py list
```

## 流程

0. **复习先于新题** — 跑 `review`。如果 `ripe` 非空（练过 ≥3 遍、还没划掉），
   先把它们念一遍给他听，一句话：这几条你会说了，但还没在真实会议里用出来。
   然后问一句：昨天有哪条真用出来了吗？他说有就 `used <id>` 划掉。
   这是设计文档第 1.4 节的"强制出队" —— 出队的唯一条件是真实会议用过，
   练得再多都不算完成。别跳过这一步，跳过了这工具就退化成刷题。

1. **开场** — 跑 `next`。打印中文题面和这一行：
   `不许查词。卡住就绕。想不出就说个笨的，笨的也算完成。`
   如果 `past` 非空，告诉他这题练过几遍、那几遍的用词今天也算重复。
   **在他写出第一遍之前，不要出现任何英文。**

2. **每一遍** — 他写完，立刻跑 `say`，只回报机器判定的结果：
   标红的句子（`【】` 包着的是重复词）、重复用词列表、新词数。
   **这一步不纠错，不评价，不夸。** 一两行说完。

3. **遍数** — 默认 **2 遍必做，第 3 遍可选**。第 2 遍报完问一句
   "再来一遍还是收？"。他说累了就收，不劝。

4. **收尾** — 问一句 better（可空），跑 `finish`，然后**一次性**给出：
   - **每一遍一处纠正**：引用原句片段 → 为什么站不住 → 最小改法。
     只看句子怎么搭（主谓宾错位、动名词乱挂、缺谓语、名词当形容词用）。
     **不挑拼写、不挑冠词、不挑时态、不挑用词高不高级。**
     判断标准是"母语者听到会不会卡一下"，不是语法书。那一遍真站得住就说站得住。
   - **3 个参考说法**：`seed_refs` 有就先用它，没有就自己写。
     只用最普通的词，三句的句子骨架必须彼此不同。

5. **记忆** — 如果这次暴露的错误模式在
   `/Users/zliu/.claude/projects/-Users-zliu-IdeaProjects-ai-note/memory/` 里
   已经记过，就更新那条（累计次数、补新例句）；是新模式才新建。
   只记**复发**的结构性模式，不记单次口误、不记拼写。

6. **页面** — 他要页面时，先加载 `artifact-design` skill，再生成：
   题面、每一遍（重复词标红）、纠正、参考说法、复发模式清单。
   同一轮练习复用同一个 artifact URL，不要每次新建。

## 他说卡住了怎么办

他说"卡住了"/"想不起来"/"不会说"时，**给中文方向，不给英文**。三种拨法：

- **问他这件事的侧面**：贵在哪？谁来做？做多久？不做会怎样？
  —— 卡住通常是因为在找那一个词，换个角度问自己，句子就自己出来了。
- **换句子骨架**：让他改成动词开头，或者拆成两个短句。
  他的复发病就是主语堆名词、没谓语。
- **允许说笨的**：提醒他"笨的也算完成"，说个小学生水平的句子交差。

**永远不给英文单词、不给英文片段、不给完整句子。** 给了他就记住我的说法，
而不是长出自己的路径 —— 这条路径正是这个工具唯一要建的东西。

## 硬规则

- **他开口之前不给英文。** 提前给答案就变成了等答案，检索训练就没了。
- **重复判定只信 `drill.py`。** 不许靠眼睛看 —— 他判不出来（说第二遍时脑子里全是第一遍），
  你也会漏。词干化 + loose match 是确定性算法。
- **不当聊天对象。** 不问"今天想聊什么"，不就话题本身展开讨论，不闲聊。
  他一旦开始和你聊天，就不在练检索了。
- **不打分、不夸、不鼓励、不寒暄。** 报数据，给一处纠正，结束。
- **一遍只挑一处。** 罗列错误会加剧"怕说错"，与训练目标直接冲突。
- **划掉的唯一条件**：他说在真实会议里用出来过。别的理由都不划。
